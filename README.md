# Innovateria - Digital Agency & Software Solutions

> **"Always Innovation is Key to Stay Relevant"**

Innovateria is a modern, high-performance web platform built with **Next.js 16**, **React 19**, **TypeScript**, and **Tailwind CSS**. It showcases enterprise software engineering, native Android/cross-platform app development, custom web application architecture, logo & graphic design, and organic SEO growth strategies.

![Innovateria Banner](public/assets/img/hero-img.png)

---

## 🚀 Key Services & Capabilities

- 📱 **Mobile App Development**: Native Android (Kotlin/Java) & cross-platform Flutter/React Native solutions with offline database sync, payment gateway integration, and real-time notifications.
- 💻 **Software Engineering**: Enterprise custom software, ERPs, and cloud architectures built for high concurrency, security, and automated workflows.
- 🌐 **Web Development**: Next.js App Router, React, and Laravel web systems engineered with responsive glassmorphism UI, fast static rendering, and SEO optimizations.
- 🎨 **Logo & Brand Design**: Modern brand identities, vector logos, design systems, and UI/UX collateral.
- 📈 **SEO & Digital Marketing**: Search engine optimization, keyword rank auditing, targeted campaign analytics, and organic growth packages.

---

## 🛠️ Tech Stack & Ecosystem

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router & Turbopack)
- **Frontend**: [React 19](https://react.dev/), [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/), Custom Glassmorphism CSS Design System
- **Icons & Motion**: [Lucide React](https://lucide.dev/), [Framer Motion](https://www.framer.com/motion/)
- **Core Technologies Handled**: React, CodeIgniter, Flutter, WordPress, Android, jQuery, Laravel, Magento, Node.js, PHP, HTML5, CSS3.

## 📱 Responsive & Adaptive Architecture

The application is engineered for **100% responsiveness** across all screen viewports:
- **Mobile Phones** (320px - 480px)
- **Mobile Landscape** (568px - 844px)
- **Tablets** (768px - 1024px)
- **Laptops & Desktops** (1024px - 1440px)
- **Ultrawide & 4K Displays** (1440px+)

Includes touch-optimized navigation drawers, scrollable mobile menus, fluid typography, and zero horizontal overflow.

## ⚡ Getting Started

### Prerequisites

- **Node.js** `v18.0.0` or higher
- **npm** `v9.0.0` or higher

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Vnjvibhash/Innovateria.git
   cd Innovateria
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🏗️ Production Build

To build the project for production:

```bash
npm run build
npm start
```
